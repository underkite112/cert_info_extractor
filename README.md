# TTA 인증서 발급용 데이터 추출기

업체명 영문명 리스트(xlsx) + 시험결과요약서(PDF, 여러 개) + 회의록(.hwp, 선택)을 업로드하면 
표지 정보를 자동으로 추출해서 인증서 제작에 필요한 필드(업체명, 제품명, 모델명, 
제조자/제조국가, 인증연월일, 유효기간, 인증기준, 인증범위, Test Highlights)를
표로 뽑아주고 엑셀로 다운로드할 수 있는 Streamlit 앱입니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 업체명 영문명 리스트 (.xlsx)

화면 ①번에 업로드하는 엑셀에 있는 값만 그대로 씁니다 (자동 검색이나 추측 없음).

- 컬럼: `업체명_국문` / `업체명_영문` 두 개뿐인 단순한 표
- 업로드하지 않으면 저장소에 기본 포함된 `company_english_names.xlsx`를 사용합니다
- 리스트에 없는 업체는 업체명_영문 칸이 빈 채로 나오고, 결과 표에서 직접 채운 뒤
  다운로드하면 됩니다. (매핑 리스트 자체를 최신으로 유지하고 싶으면, 평소 관리하시는
  엑셀 파일에 새 업체를 추가해서 다음번에 ①번에 업로드하시면 됩니다.)

## 주의사항 / 한계

- **추출 로직은 정규식/좌표 기반**이라, 시험결과요약서 표지 레이아웃이 학습시킨 6개
  양식들과 크게 다르면 일부 필드가 비거나 잘못 들어갈 수 있습니다. 화면의 표는
  `st.data_editor`로 바로 수정 가능하니, 다운로드 전에 한 번씩 확인하세요.
- `.hwp` 회의록 파싱은 `pyhwp`(hwp5html)를 사용합니다. Streamlit Cloud 등
  일부 환경에서는 시스템 패키지 제약으로 설치가 안 될 수 있으니, 안 될 경우
  회의록 없이 쓰거나 로컬에서 표 내용을 미리 텍스트로 뽑아 붙여넣는 방식으로
  우회하세요.
- 제조자 표기가 아예 없으면 업체명을 그대로 사용합니다.
- 영문 업체명은 업로드한 리스트에 없으면 빈 칸으로 남습니다.
  (인증서에 그대로 들어가는 값이므로, 정확한 영문명은 업체 확인 후에 사용 바랍니다.)
